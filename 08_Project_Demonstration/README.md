# Phase 8 – Project Demonstration

# Project Title

PocketSmart AI – Your Smart Budget & Recommendation Assistant

## 1. Introduction

The project demonstration phase presents the completed PocketSmart AI application and explains its purpose, features, workflow, and final output.

The demonstration should show the actual working application rather than only presenting source code.

## 2. Demonstration Objectives

The demonstration should explain:

- What PocketSmart AI is.
- Why the project was developed.
- The problems it addresses.
- The major features.
- How users interact with the application.
- How AI recommendations are generated.
- How different planning modules work.
- The final output of the application.

## 3. Demonstration Flow

The recommended demonstration flow is:

### Step 1 – Introduction

Introduce the project:

**PocketSmart AI – Your Smart Budget & Recommendation Assistant**

Explain that it is an AI-powered recommendation application designed to assist users with budget-based planning.

### Step 2 – Explain the Purpose

Explain the main purpose of the project:

- Help users plan within a budget.
- Provide AI-generated recommendations.
- Reduce manual searching.
- Support different planning categories.

### Step 3 – Show the Application

Open the running PocketSmart AI application and show the main interface.

Explain the major navigation options and available features.

### Step 4 – Registration

Demonstrate user registration if applicable.

Show how a new user can create an account.

### Step 5 – Login

Log into the application using a valid account.

Explain that authentication provides access to user-specific functionality.

### Step 6 – Home Interior Recommendation

Open the home interior planning feature.

Enter suitable sample requirements and budget information.

Submit the request and demonstrate the generated recommendations.

### Step 7 – Party Planning Recommendation

Open the party planning feature.

Enter sample event requirements and budget information.

Submit the request and show the generated recommendations.

### Step 8 – Jewelry Recommendation

Open the jewelry recommendation feature.

Enter suitable requirements and budget information.

If image input is supported, demonstrate the image upload functionality.

Submit the request and show the generated recommendations.

### Step 9 – Recommendation History

Open the recommendation history functionality.

Show how previous recommendation information can be accessed.

### Step 10 – Explain AI Functionality

Explain that the recommendation system uses Google Gemini to process the provided information and generate recommendations.

### Step 11 – Final Output

Show the final recommendation results generated by the application.

Explain how the recommendations relate to the user's provided requirements and budget.

## 4. Benefits Demonstrated

The demonstration should highlight the following benefits:

- Budget-aware planning.
- AI-powered recommendations.
- Multiple planning categories.
- Personalized user input.
- Centralized recommendation system.
- Recommendation history.
- Easy-to-use web interface.

## 5. Demo Video Requirements

The project demonstration video should include:

- Screen recording.
- Student voice-over.
- Project name.
- Project purpose.
- Project benefits.
- Application execution.
- Working process.
- Final output.
