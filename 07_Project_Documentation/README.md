# Phase 7 – Project Documentation

# Project Title

PocketSmart AI – Your Smart Budget & Recommendation Assistant

## 1. Project Overview

PocketSmart AI is an AI-powered web application designed to provide budget-aware recommendations for different planning requirements.

The main planning categories are:

- Home Interior Planning
- Party Planning
- Jewelry Planning

The system combines a web interface, FastAPI backend, database, authentication, and Google Gemini AI.

## 2. Purpose

The purpose of PocketSmart AI is to simplify planning by allowing users to provide their requirements and budget and receive AI-generated recommendations.

## 3. Key Features

The main features include:

- User registration.
- User login.
- User logout.
- Session management.
- Home interior recommendations.
- Party planning recommendations.
- Jewelry recommendations.
- Budget-based recommendation generation.
- AI-powered suggestions.
- Recommendation history.
- Image input support for jewelry recommendations where implemented.
